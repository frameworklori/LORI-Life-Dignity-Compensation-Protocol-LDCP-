# Repository Map

This map explains the reorganized LDCP repository structure.

## 00-overview

Purpose: orientation layer.

Contains:

- Glossary
- Core principles
- Governance summary
- Date and privacy notes
- Repository map

Use this folder first when reviewing the protocol.

## 01-core-protocol

Purpose: LDCP core framework.

Contains:

- Core LDCP model
- Premium adjustment model
- Scoring system
- Anti-abuse annex

Use this folder to understand the protocol's central ethical and compensation logic.

## 02-compensation-models

Purpose: compensation architecture and affordability controls.

Contains:

- Layered implementation framework
- Safety-valve logic
- Affordability model
- Audit KPIs
- Compensation modules
- Healthcare safety net
- Resource scarcity adjuster

Use this folder when translating dignity principles into compensation design.

## 03-governance

Purpose: decision-making and review procedure.

Contains:

- Jury roles
- Voting protocol
- Appeals process
- Jury decision packet
- Anti-manipulation checks

Use this folder when designing review panels or institutional oversight.

## 04-risk-and-evidence

Purpose: evidence integrity and ODRAF risk logic.

Contains:

- Evidence guardrails
- ODRAF core
- Risk weights

Use this folder when evaluating severity, causation, and responsibility.

## 05-feedback-loop

Purpose: accountability after compensation.

Contains:

- Drift checks
- Feedback loop
- Verdict-to-compensation mapping

Use this folder to prevent LDCP from becoming a one-time payout process.

## 06-domain-cases

Purpose: scenario examples and domain-specific applications.

Contains:

- AI displacement cases
- Healthcare coverage cases
- Substance abuse guardrail case
- AI displacement bilingual notes

Use this folder to test whether the protocol is understandable across domains.

## 07-digital-transition

Purpose: digital transition and platform-specific adaptation.

Contains:

- Digital transition principles
- Federal student loan context
- EPS modeling addendum
- Scope and non-objectives
- Use cases

Use this folder for policy or digital-service implementations.

## 08-schemas

Purpose: structured data definitions.

Contains:

- Compensation schema
- ODRAF profile schema
- Verdict schema

Use this folder when building software or structured review tools.

## 09-tools

Purpose: simulation and prototype layer.

Contains:

- Python simulations
- Jury vote simulator
- LDPC engine
- ODRAF scoring prototype

Use this folder for early testing and internal demonstrations.

## 10-legal

Purpose: legal and authorship records.

Contains:

- Authorship declaration
- Commercial protection clause
- Originality trace
- Semantic fingerprint

Use this folder for attribution and provenance.

## 11-assets

Purpose: diagrams and images.

Contains:

- Semantic flow image

Use this folder for visual explanation.

## implementation

Purpose: real-world adoption layer.

Contains:

- Feasibility plan
- Pilot roadmap
- Operational workflow
- Source plans

Use this folder when moving from concept to institutional trial.
